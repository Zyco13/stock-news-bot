# stock-news-bot

米国株のウォッチ銘柄に関するニュースを毎朝自動で集め、AIで関連するものだけを選んで日本語で要約し、Discordに届けるツールです。

## 作った理由

　英語のニュースに反応するのが遅れるし朝からニュースに触れたいと考えたから

## できること

- ウォッチリストの銘柄ごとに、直近のニュースを自動で取得
- AIが「その銘柄に関係あるか」を判断し、関係ないニュースを除外
- 関係あるニュースを日本語2行で要約
- 毎朝7時（日本時間）にDiscordへ自動通知

## 仕組み

1. Finnhub APIで銘柄ごとのニュースを取得
2. Gemini APIで関連性の判断と日本語要約
3. Discord Webhookで通知
4. GitHub Actionsで毎朝自動実行

## 使用技術

Python / Finnhub API / Gemini API / Discord Webhook / GitHub Actions

## 工夫した点

- **関連性の判断基準の調整**：最初は関係ないニュースが混ざり、基準を厳しくすると今度は重要なニュースまで消えてしまった。「その会社が主役」または「株価に直接影響しそう」という2つの基準にすることで、バランスを取った。
- **エラー対策**：AIのサーバーが混雑して処理全体が止まることがあったため、失敗したら待って再試行し、それでもだめならその記事だけ飛ばすようにした。
- **APIキーの管理**：キーはコードに書かず、GitHub Secretsで管理している。
